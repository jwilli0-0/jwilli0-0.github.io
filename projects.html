A React-Vite based project created to help motivate users to DIY recycable materials. In a team, I was able to use elements of Scrum and utilize Github to create a unique project in a team of 4. We were able to simulate the design of social media apps by storing user data in firebase databases.


Tools Utilized:

  • Github/Git: Used to collaborate with team members as they would complete different aspects of the project. I would often pull and commit any changes to the project.
  • React Vite: The base of the project, during my software engineering class, I was able to get some insight on how to use react and create a web application.
  • Javascript: A large aspect of the project used Javascript to include functionality within the app. Users gaisned the ability to sign up, log in, access post information from our personal database, and more.
  • HTML: The markdown language helped for users to visualize our social media app. Helping to include various buttons, post layout, and input fields.
  • FirebaseWe decided to use Firebase to maintain 2 seperate databases for our project. First, user information and secondly, post information.
  • CSS & Bootstrap API: Both tools heloed us to better the style of the porject to help appeal to audiences.
